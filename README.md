# ALI & WAED — دعوة زفاف رقمية فاخرة

دعوة زفاف تفاعلية بالعربية (RTL): الشاشة لا تفتح إلا بعد لمس المستخدم لها،
عندها يشتغل فيديو الدعوة (الختم الأحمر، الشعار)، وعند انتهائه تنكشف الدعوة
الكاملة: آية قرآنية، بطاقات "احفظوا الموعد" القابلة للحك، دعوة رسمية بأسماء
الأهل، تفاصيل عقد القران، عد تنازلي، الجدول الزمني، الموقع، ومعرض صور.
كل قسم يحمل نفس زخرفة الفوانيس والزهور الخفيفة بشكل موحّد ومتحرك بنعومة.

مبنية بـ HTML/CSS/JS خام — بدون أي إطار عمل أو خطوة بناء (build step).

---

## 1. فتح المشروع في VS Code

1. فك ضغط مجلد `wedding-invitation` في أي مكان على جهازك.
2. من VS Code: **File → Open Folder…** ثم اختر المجلد.

## 2. التشغيل محليًا

تحتاج خادوم محلي (فتح `index.html` مباشرة بصيغة `file://` قد يمنع تشغيل
الفيديو والخطوط في بعض المتصفحات). أسهل الطرق:

- إضافة **Live Server** في VS Code، ثم كليك يمين على `index.html` واختر
  **Open with Live Server**.
- أو من الطرفية:
  ```bash
  cd wedding-invitation
  python3 -m http.server 5500
  ```
  ثم افتح `http://localhost:5500` في المتصفح.

لا حاجة لـ `npm install` — لا يوجد أي خطوة بناء.

## 3. مكان الملفات

```
wedding-invitation/
├── index.html          ← البنية فقط، بدون أي محتوى ثابت مكتوب داخله
├── config.js            ← كل المحتوى القابل للتعديل — عدّل هذا الملف فقط
├── css/                 ← التصميم، مقسّم حسب الغرض
├── js/                  ← وحدة صغيرة لكل ميزة
└── assets/
    ├── images/          ← صورة الغلاف، صورة الموقع، صور المعرض
    ├── videos/            envelope-intro.mp4 (فيديو الفتح) + couple-walking.mp4 (الفيديو الرئيسي)
    └── audio/             wedding.mp3 (اختياري)
```

## 4. استبدال الوسائط

| العنصر | المكان | ملاحظات |
|---|---|---|
| فيديو الفتح (الختم) | `assets/videos/envelope-intro.mp4` | يشتغل فقط بعد لمس الشاشة، وعند انتهائه تنكشف الدعوة تلقائيًا |
| فيديو العروسين | `assets/videos/couple-walking.mp4` | عمودي (9:16)، يظهر داخل الإطار القوسي في القسم الأول |
| صورة الموقع | `assets/images/venue.webp` | حاليًا صورة مؤقتة (placeholder) — استبدلها بصورة حقيقية |
| صور المعرض | `assets/images/photo-01.webp` … `photo-06.webp` | صور مؤقتة أيضًا؛ عدّل القائمة في `config.js → gallery` لإضافة/حذف صور |
| موسيقى خلفية (اختياري) | `assets/audio/wedding.mp3` | لا يوجد ملف افتراضيًا؛ أضف MP3 هنا وسيعمل بعد الضغط على زر الصوت |

## 5. تعديل المحتوى — ملف `config.js` فقط

كل نص في الموقع يأتي من `invitationConfig` داخل `config.js`. لا حاجة لمس
الـ HTML أو CSS أو الأنيميشن لتحديث أي معلومة عن الحفل.

- **الأسماء** — `couple.groom`, `couple.bride`, `couple.monogram`
- **أسماء الأهل** — `couple.groomFamily`, `couple.brideFamily`
- **التاريخ والوقت** — `event.isoDateTime` (يحرّك العد التنازلي تلقائيًا)،
  و`event.day` / `event.displayDate` / `event.time` للعرض بالعربية
- **المكان والعنوان** — `event.venue`, `event.address`
- **رابط خرائط جوجل** — `event.mapsUrl`, `event.directionsUrl`
- **رسالة الدعوة / رسالة الختام** — `content.invitationMessage`,
  `content.familyMessage`, `content.finalMessage`
- **الآية القرآنية** — `quran.*` (الرجاء عدم تعديل النص القرآني)
- **الجدول الزمني** — عدّل مصفوفة `timeline` (وقت + عنوان لكل بند)
- **معرض الصور** — أضف/احذف مسارات الصور داخل `gallery`
- **تفعيل/تعطيل العد التنازلي** — `countdown.enabled`
- **تفعيل/تعطيل الموسيقى** — `music.enabled`

مثال — تغيير المكان:

```js
event: {
  ...
  venue: "اسم القاعة الجديد",
  address: "العنوان الجديد",
}
```

احفظ الملف — العد التنازلي وتفاصيل عقد القران وقسم الموقع تتحدّث تلقائيًا.

## 6. تعديل الزخرفة (الفوانيس والزهور)

كل قسم يحصل تلقائيًا على نفس مجموعة الزخرفة (فانوسان حقيقيان أعلاه، باقة
أزهار زرقاء في كل زاوية، وباقة ورد شفافة أسفله) من ملف واحد فقط:
`js/decor.js` — لا حاجة لتكرار أي كود يدويًا في كل قسم. الصور نفسها موجودة
في `assets/images/decor/`:

| الملف | الاستخدام |
|---|---|
| `lantern.webp` | الفانوسان أعلى كل قسم (يمين ويسار) |
| `blue-flowers.webp` | باقة الأزهار الزرقاء في الزوايا الأربع |
| `vintage-bouquet.webp` | الباقة الشفافة أسفل كل قسم |
| `rose-frame-circle.webp` | الإطار الدائري خلف شعار "A & W" في قسم الأسماء |
| `gold-frame.webp`, `paper-bouquet.webp` | متوفرتان للاستخدام اليدوي إن رغبت بإضافة زخرفة في مكان معيّن |

لتغيير الصور نفسها، استبدل ملف الـ webp بنفس الاسم داخل `assets/images/decor/`.
لتغيير الحجم أو الشفافية أو سرعة الحركة، عدّل قواعد `.decor-lantern` و
`.decor-corner` و`.decor-bouquet` داخل `css/invitation.css` (قسم "Section
decoration" قرب نهاية الملف). الأقسام ذات الخلفية الداكنة (العد التنازلي
والختام) تُعرض بسطوع أعلى قليلًا تلقائيًا لتبقى واضحة، عبر كلاس
`section-decor--dark`.

## 7. النشر والحصول على رابط قابل للمشاركة

بما أن المشروع بالكامل ملفات ثابتة (بدون كود خادوم)، يمكن نشره مجانًا خلال
دقائق عبر:

- **Netlify** — اسحب مجلد `wedding-invitation` إلى app.netlify.com/drop
- **Vercel** — نفّذ `npx vercel` داخل المجلد
- **GitHub Pages** — ادفع المجلد إلى مستودع وفعّل Pages من الإعدادات
- **Cloudflare Pages** — اربط المستودع أو اسحب المجلد مباشرة

## 8. ملاحظات على السلوك

- لا يمكن التمرير (scroll) قبل لمس الشاشة وتشغيل فيديو الفتح — هذا مقصود
  حتى يعيش الزائر لحظة الفتح كاملة.
- **الصوتيات:** لحظة النقر على الشاشة لأول مرة، يشتغل صوت فيديو فتح
  الدعوة (بصوته الأصلي) والأغنية الخلفية سوا بنفس الوقت. فيديو العروسين
  بقسم الفيديو الرئيسي دايمًا بلا صوت ولا يوجد أي زر يشغّله. زر الصوت
  الوحيد بالموقع (الدائرة الحمراء الثابتة أعلى يمين الشاشة) يتحكم فقط
  بالأغنية الخلفية، ويضل ظاهرًا مهما مرّر الزائر لأي قسم بالصفحة.
- الديكور (الفوانيس والزهور) موحّد وموجود في كل قسم عبر ملف واحد
  (`js/decor.js`) بدل تكراره يدويًا — بشكل خفيف وشفاف حتى لا يطغى على
  النص: "الفخامة تأتي من البساطة والتنظيم لا من الحشو".
- التصميم متجاوب بالكامل: على الهاتف يملأ الشاشة، وعلى شاشات اللابتوب/
  الكمبيوتر يبقى بعرض بطاقة أنيقة في المنتصف بدل التمدد الكامل.
- يُحترم إعداد `prefers-reduced-motion`: عند تفعيله، يُفتح القسم الرئيسي
  مباشرة بلمسة واحدة دون تشغيل الفيديو الكامل (والأغنية بتشتغل بنفس تلك
  اللمسة أيضًا).
